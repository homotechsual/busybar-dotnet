## Reporting a Vulnerability

Please report vulnerabilities via "Security and quality" on GitHub or via this link: https://github.com/homotechsual/busybar-dotnet/security/advisories/new

We will endeavour to keep you updated as investigation and fix work progresses - this may be via public security advisories.
